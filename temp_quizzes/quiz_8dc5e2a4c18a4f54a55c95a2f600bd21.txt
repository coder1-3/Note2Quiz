1. Which of the following is not a Python feature related to data types?
   A) Use of square brackets [] for creating lists
   B) Use of curly braces {} for defining dictionaries
   C) Use of the 'def' keyword for defining functions
   D) Use of the 'print()' function for outputting data
   Answer Key: D
2. In Python, what is used to specify that a variable should be used for the entire block of code?
   A) Indentation
   B) Square brackets
   C) Curly braces
   D) None of the above
   Answer Key: A
3. What is the correct way to write a Python function?
   A) def function_name(arg1, arg2, ...):
   B) def function_name(arg1, arg2, ...):
   C) function_name(arg1, arg2, ...):
   D) function_name(arg1, arg2, ...):
   Answer Key: A
